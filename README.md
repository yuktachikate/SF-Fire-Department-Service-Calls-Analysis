
# SF Fire Department Service Calls Analysis

This project analyzes San Francisco Fire Department service calls, focusing on response times and call types across neighborhoods. It includes visualizations to identify areas with high emergency volumes and response delays, aiming to optimize emergency services.

## Key Features:
- **Call Type Analysis**: Visualizations showing the breakdown of service calls by type (e.g., fire, medical emergencies).
- **Neighborhood Analysis**: Identification of neighborhoods with the highest call volumes and potentially life-threatening situations.
- **Response Time Visualization**: Bar graphs to highlight areas with longer travel times for emergency responders, suggesting where improvements are needed.

## Technologies Used:
- Python
- Pandas
- Matplotlib / Seaborn
- Jupyter Notebooks

## Data:
The data used for this analysis includes service call records from the SFFD, focusing on 2018. It includes timestamps, locations, and types of emergency calls.

## How to Run:
